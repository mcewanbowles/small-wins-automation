Brown Bear I Spy & Count | 4 Differentiated Levels

Build visual scanning, one-to-one counting, and early number recognition with a differentiated Brown Bear I Spy routine for special education, autism support, and early years classrooms.

WHAT'S INCLUDED
- 4 leveled I Spy activity pages
- Number tile cutouts for hands-on response options
- Answer key
- Color and black and white versions
- Quick Start Guide
- Terms of Use / Credits

WHY TEACHERS LOVE THIS RESOURCE
- Predictable routine that keeps students engaged while practicing core math concepts
- Easy differentiation from supported counting to more independent number selection
- Print-and-go setup with reusable options for centers and intervention groups
- Cost-effective repeated use across multiple goal levels

HOW TO USE
1) Print color or B&W pages
2) Prep number tiles (laminate/Velcro optional)
3) Students scan and count target images on each page
4) Students place or write the matching number
5) Use answer key for fast checks and move to next level challenge
