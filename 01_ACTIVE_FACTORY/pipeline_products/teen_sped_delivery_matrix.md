# Teen SpEd Delivery Matrix (Cyber + Hygiene)

## Format strategy (default)
1. **PDF printable** = core product
2. **Google Slides editable** = main adaptation format for teachers
3. **Easel activity** = interactive subset only

---

## Product A: Cyber Safety Lesson + Practice

### What to include in PDF (core)
- Teacher lesson plan (10 / 20 / 30 min options)
- Student mini-book
- Routine strips: Notice -> Stop -> Do not reply -> Save evidence -> Block -> Tell trusted adult
- Pocket cards + AAC board
- Scenario cards (print-cut)
- Data sheet + caregiver carryover page

### What to include in Google Slides
- Editable lesson script (tone, language level, age version)
- Editable scenario cards (swap names/devices/platform examples)
- Editable labels for icons/actions
- Differentiation deck versions (reader / emerging reader / AAC)

### What to include in Easel
- Scenario sort (safe/unsafe)
- Sequence routine drag-drop
- Choose-the-best-response multiple choice
- Vocabulary match (message, block, report, evidence, trusted adult)

### Keep out of Easel
- Long mini-book pages
- Dense teacher guidance pages
- Parent letters

---

## Product B: Body Hygiene & Grooming Independence

### What to include in PDF (core)
- Teacher lesson plan + objective + materials
- Teen-respectful mini-book pages
- Visual routines (teeth, deodorant, grooming, bathroom hygiene)
- Practice strips (first-next-then)
- Role-play / social script cards
- Progress checklist + home-school carryover

### What to include in Google Slides
- Editable wording for sensitivity/age level
- School/home routine variants
- Personalized routine pages (student name, times, supports)
- Alternate scripts for private prompts

### What to include in Easel
- Sequence routine tasks (e.g., brushing steps)
- What-to-use matching (item -> action)
- Public vs private sorting for hygiene behaviors
- Quick comprehension checks

### Keep out of Easel
- Sensitive full narratives requiring teacher mediation
- Detailed staff protocol pages

---

## Practical rule of thumb
- If it needs **printing + repeated real-world use** -> PDF
- If teachers need to **edit/adapt quickly** -> Google Slides
- If students need **interactive click/drag practice** -> Easel

---

## Build order
1. Cyber Safety: PDF -> Slides -> Easel
2. Body Hygiene: PDF -> Slides -> Easel
3. Public vs Private Boundaries: PDF -> Slides first, Easel only selective pages
