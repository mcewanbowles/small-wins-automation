# Life Skills 4-Product Roadmap

## 1) Personal Hygiene Independence
- Format: mini-book + visual schedule + routine strips + data sheet
- Core lessons: teeth, deodorant/body care, nails/grooming, period hygiene
- Reusable pages: cover, 6-8 mini-book pages, first-next-then strips, yes/no choice cards, home practice checklist

## 2) Public vs Private Body Boundaries
- Format: explicit lesson pack + scenario sort + replacement action cards
- Core lessons: private vs public places/behaviors, what to do instead, trusted-adult help
- Reusable pages: rules anchor chart, scenario sorting, routine strip (Stop -> Move -> Ask)

## 3) Personal Space and Social Boundaries
- Format: social behavior lesson + role-play cards + mini-book
- Core lessons: personal space, consent/no, safe touch boundaries, ask-help-move away
- Reusable pages: social script mini-book, role-play prompt cards, reflection sheet

## 4) Cyber Safety Lesson and Practice
- Format: mini-lesson + response routine + portable quick cards
- Core lessons: unsafe contact, bullying/scam cues, block/report/save evidence, tell trusted adult
- Reusable pages: vocabulary cards, scenario cards, action routine strip, parent/staff handout
