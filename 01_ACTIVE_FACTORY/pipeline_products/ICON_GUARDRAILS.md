# Icon Selection Guardrails — Small Wins Studio

## Purpose
Rules for selecting, creating, and mapping icons for SPED/AAC resources.
These apply to ALL products across the StudioForge pipeline.

---

## 1. CORE PRINCIPLE: Concrete > Abstract

Non-verbal and minimally speaking students learn through concrete visual representation.
An icon must show something the student can SEE in the real world.

| Good (concrete) | Bad (abstract) | Why |
|-----------------|----------------|-----|
| bedroom (a bed) | private (a lock?) | "bedroom" shows a real place; "private" is a concept |
| bathroom (a toilet) | privacy (a curtain?) | "bathroom" is recognisable; "privacy" requires inference |
| stop (a stop sign) | respect (??) | "stop" is universally recognised; "respect" has no visual |
| door (a door) | boundary (a line?) | "door" is concrete; "boundary" is abstract |

### Rule 1a: If you cannot draw it as a single object, it is not a good icon
### Rule 1b: If the student has to INFER meaning, the icon is too abstract
### Rule 1c: When an abstract concept is needed, use a concrete SUBSTITUTE

Abstract concept → concrete substitute examples:
- "private" → use a door (closed) or a bedroom icon
- "public" → use a group of people or a building
- "respect" → use a smile or a handshake (or remove the icon — see Rule 6)
- "safe" → use a shield or a stop sign (context-dependent)
- "trust" → use a handshake or a known adult figure
- "consent" → use a yes/checkmark or a handshake
- "report" → use a phone or a teacher/adult figure
- "uncomfortable" → use a face expression or remove (see Rule 6)

---

## 2. NOUNS ARE BEST, VERBS ARE RISKY

### Rule 2a: Nouns make the best icons
Nouns represent objects, places, or people that are visually concrete.
Examples: bedroom, bathroom, pants, door, phone, bus, teacher, friend

### Rule 2b: Verbs are ambiguous — use with caution
Many verbs have multiple meanings and the icon may show the wrong one.

| Verb icon | Problem | Better alternative |
|-----------|---------|-------------------|
| "break" | Could mean break a thing, take a break, break time | Use "break time" (PCS has this) or a clock |
| "touch" | Could mean touch anything, touch self, touch someone | Pair with context (hand + body) or use a hand icon |
| "help" | Generally OK — PCS help icon is clear | Usually fine |
| "stop" | Generally OK — stop sign is universal | Usually fine |
| "play" | Could mean play a game, play music, play outside | Usually fine in context |
| "wash" | Could mean wash hands, wash body, wash clothes | Use "wash hands" specifically |

### Rule 2c: When using a verb icon, pair it with a noun for clarity
- "wash" alone is ambiguous → "wash hands" is clear
- "touch" alone is ambiguous → "touch body" or "hands on body" is clearer
- "break" alone is ambiguous → "break time" is clearer

---

## 3. AVOID AMBIGUOUS ICONS

### Rule 3a: One icon = one meaning
If an icon could mean two different things in the same product, it is ambiguous.

### Rule 3b: Avoid icons that look similar to other icons
- "door" and "door closed" should be visually distinct
- "bathroom" and "toilet" should not both appear (pick one)
- "bedroom" and "bed" should not both appear (pick one)

### Rule 3c: Avoid icons with multiple subjects
Icons showing several people doing different things are confusing for non-verbal students.
Use single-subject icons wherever possible.

---

## 4. PEOPLE AND BODY PARTS

### Rule 4a: Use neutral, non-specific person figures
PCS "person" or "adults" icons are preferred over specific individuals.
Avoid gendered or culturally specific figures unless the topic requires it.

### Rule 4b: Body parts must be clinical, not suggestive
For body safety topics:
- Use body outline/silhouette icons, not detailed anatomy
- Use "body parts" (PCS) for the general concept
- Use "underwear" or "swimsuit" to indicate private areas (not body parts themselves)
- The Vanderbilt/Autism NZ guidance: use correct anatomical terms in TEXT but symbolic/covered representations in ICONS

### Rule 4c: Touch icons must show the ACTION, not the body part
- "touch" icon should show a hand reaching, not a body part being touched
- Avoid icons that could be interpreted as sexual

---

## 5. CONSISTENCY WITHIN A PRODUCT

### Rule 5a: Each product uses ONE icon style
Do not mix PCS symbols with photographs or clipart within the same product.
All Small Wins Studio products use PCS symbols (licensed).

### Rule 5b: Each concept uses ONE icon across the product
If "bathroom" appears on the social story, the cut-out pieces, the routine strip, and the AAC board, it should be the SAME icon in all of them.

### Rule 5c: Icon size and placement should be consistent
The same icon should appear at a similar size and position across all pages of a product.

---

## 6. WHEN TO OMIT AN ICON

### Rule 6a: If no good icon exists, use TEXT ONLY
A missing icon is better than a confusing icon.
If a concept is too abstract for a clear visual, show the text without an icon box.

### Rule 6b: Do not force an icon onto every concept
Some concepts are better communicated through:
- The social story text itself
- Teacher guidance notes
- Discussion prompts
- The student's AAC device (which has its own vocabulary)

### Rule 6c: Abstract concepts that should NOT have icons
These concepts should be taught through text and discussion, not icons:
- respect
- dignity
- boundaries (as a concept — "boundary" as a physical line is OK)
- consent (as a concept — "yes/no" icons are OK)
- trust
- privacy (as a concept — "door closed" is OK as concrete substitute)
- uncomfortable (as a feeling — face expression icons are OK but may be too subtle)

---

## 7. PCS-SPECIFIC RULES

### Rule 7a: Use the canonical PCS name when searching
PCS uses specific naming conventions. When mapping our icon names to PCS:
- "bathroom" → PCS "bathroom" (not "restroom" or "toilet")
- "bedroom" → PCS "bedroom" (not "bed" or "room")
- "stop" → PCS "stop" (the stop sign version, not "stop 2")
- "help" → PCS "help" (the standard help icon)
- "wash hands" → PCS "wash hands" (not just "wash")
- "finished" → PCS "finish" or "finish(ed)"

### Rule 7b: Prefer the simplest version of a PCS icon
PCS often has multiple versions (e.g. "stop", "stop 1", "stop 2", "stop g").
Use the base name version, not numbered variants.
"stop g" is the greyscale version — only use for BW products.

### Rule 7c: Check the PCS "e" suffix
PCS icons ending in "e" are often "ethnic" or alternate versions.
Use the base version for neutrality.

## 8. TOPIC-SPECIFIC RULES

### Body safety / private touching topics
- Use "bedroom" and "bathroom" as concrete private place icons
- Use "door" (closed) as the privacy concept icon
- Use "stop" (stop sign) as the "hands out" reminder icon
- Use "play" or "fidget" as the "hands busy" replacement icon
- Use "adults" or "teacher" as the "safe adult" icon
- Do NOT use "masturbation" PCS icon in student-facing materials (it exists in the Sexual category but is for clinical/teacher reference only)
- Use "body" (body outline) for body ownership — not detailed anatomy

### Online safety topics
- Use "phone" or "portable computer" for device icons
- Use "stranger" for unknown person online
- Use "block" (blocks) for blocking content
- Use "camera" for photo/screenshot concepts
- Do NOT use generic "internet" icons — use the specific device

### Hygiene / body care topics
- Use "wash hands" specifically (not just "wash")
- Use "deodorant" for body odour
- Use "soap" for cleaning
- Use "toilet" or "bathroom" for toileting
- Use "clothes" for dressing

---

## 9. ICON NAMING CONVENTIONS

### Rule 9a: Our icon names use snake_case
- `wash_hands` not `wash hands` or `washHands`
- `door_closed` not `door closed` or `doorClosed`

### Rule 9b: Our icon names describe the CONCEPT, not the PCS filename
- Our name: `safe_adult` → PCS file: `adults`
- Our name: `finished` → PCS file: `finish`
- Our name: `wash_hands` → PCS file: `wash hands`

### Rule 9c: When creating custom icons, name them by concept
- `private_place.png` (a door with a closed sign)
- `public_place.png` (a building with people)
- `hands_busy.png` (hands holding a fidget)

---

## 10. REVIEW CHECKLIST

Before finalising an icon for a product, check:

- [ ] Is it concrete? (Can the student see this in the real world?)
- [ ] Is it unambiguous? (Does it have only one obvious meaning?)
- [ ] Is it consistent? (Is it the same icon used elsewhere in this product?)
- [ ] Is it appropriate? (Is it age-appropriate and non-suggestive?)
- [ ] Is it recognisable? (Would a non-verbal teen recognise it?)
- [ ] Is it a noun or clear action? (Not an abstract concept?)
- [ ] Does it match the text? (Does the icon match the sentence on the page?)
- [ ] Is it the simplest version? (Not a numbered PCS variant?)

If ANY answer is "no", consider:
1. Using a concrete substitute
2. Using text only (no icon)
3. Removing the concept from the visual and teaching it through discussion instead
